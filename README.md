# Callsign Lookup

Offline FCC Amateur & GMRS license lookup for Windows. Search by callsign,
name, FRN or city, log net check-ins, and map who checked in. The FCC data
lives on your own PC and refreshes itself every morning.

## Download

**[Get the latest installer](https://github.com/hamtool-hub/callsign-lookup/releases/latest)**
— under **Assets**, click the `.exe` file.

## Install

1. Run the installer. Windows may show **"Windows protected your PC"**
   because the program isn't from a big publisher — click **More info → Run anyway**.
2. The first install downloads the full FCC database. It takes **15–30 minutes**
   with no visible progress, so let it run.
3. When it finishes, open **Callsign Lookup** from your desktop. It runs in
   your web browser at `http://localhost:8091`.

**Needs:** Windows 10 or 11, an admin account for the install, an internet
connection, and about 2 GB of free disk space.

## Updating

Run the newest installer over the top of your current version. Your log
and saved repeaters are kept.
